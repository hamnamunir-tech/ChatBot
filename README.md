🤖 Simple ChatBot

SimpleBot is a basic conversational AI built using the ChatterBot Python library. It can interact with users in English, providing responses based on a pre-trained corpus. This project is ideal for beginners learning about chatbots and natural language processing.

🔍 Features

Conversational AI using ChatterBot

Trained with English language corpus

Interactive console interface

Simple, lightweight, and easy to extend

🛠️ Technologies Used

Python 3

ChatterBot library

ChatterBotCorpusTrainer for training the bot

🚀 How It Works

Create a chatbot instance using ChatBot()

Train it using ChatterBotCorpusTrainer with English corpus

Interact with the bot in the console by typing messages

Type "quit" to exit the conversation

💻 Usage

Install required packages:

pip install chatterbot
pip install chatterbot_corpus


Run the chatbot script:

python simple_chatbot.py


Chat with the bot in the terminal.

📝 Example Interaction
You: Hello
Bot: Hi there!
You: How are you?
Bot: I am doing well, thank you.
You: quit
